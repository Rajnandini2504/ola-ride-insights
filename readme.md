# 🚖 Ola Ride Insights Dashboard

An end-to-end Data Analytics project focused on analyzing ride-sharing data using SQL, Power BI, and Streamlit.

---

## 📌 Project Overview

The Ola Ride Insights project aims to analyze ride booking data to extract meaningful business insights.  
The solution includes:

- Data Cleaning & Preprocessing
- SQL Query Analysis
- Power BI Interactive Dashboard
- Streamlit Web Application Deployment

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- SQL
- Power BI

---

## 📊 Key Features

- Ride Volume Over Time Analysis
- Booking Status Breakdown
- Revenue by Payment Method
- Top 5 Customers by Booking Value
- Driver & Customer Ratings Analysis
- Cancellation Insights
- Vehicle Type Performance
